
# Library Management System

## Project Description
A Java-based library management system.

## Features
- Book management
- Exception handling
- File path checking
- CSV file storage
- Loading and saving book information

## Java Classes
- ExceptionWarmUp.java
- BookExceptionCheck.java
- PathExplorer.java
- BookFileStore.java
- LibraryService.java
- Main.java

## CSV Storage
Book information is stored in:

data/books.csv

The application can load and save book information using CSV files.

## How to Run
1. Open the project in your Java IDE.
2. Run Main.java.
3. The application loads book information.
4. The application displays the books.
5. The application saves the information to the CSV file.
